
# Práctica de Maquetación con Bootstrap 5

Este repositorio contiene una práctica de desarrollo frontend centrada en la construcción de interfaces responsivas utilizando Bootstrap 5 a través de CDN.

## Características del Proyecto

* **Barra de Navegación (Navbar):** Menú colapsable en dispositivos móviles utilizando el componente nativo de Bootstrap.
* **Sistema de Grillas:** Diseño adaptable que reorganiza el contenido según el tamaño de la pantalla (3 columnas en escritorio, 2 en tablet y 1 en móvil).
* **Componentes Visuales:** Uso de tarjetas (Cards) con imágenes dinámicas, títulos y descripciones.
* **Ventana Interactiva (Modal):** Implementación de un modal con mensaje de bienvenida accionado por un botón central.
* **Clases Utilitarias:** Aplicación directa de utilidades de Bootstrap para controlar márgenes, sombras, colores de fondo (`bg-light`, `bg-dark`), bordes redondeados y tipografía (`text-primary`, `fw-bold`) sin CSS personalizado.

## Tecnologías Utilizadas

* HTML5
* Bootstrap 5.3.2 (CSS y JavaScript vía CDN)
